One line of horror: a single sentence, under 200 characters, that has to frighten a reader in one breath. No setup, no paragraph, no second chance — just a baby monitor, a familiar voice, and the wrong room.

## The line

> The baby monitor whispered my name tonight — in my voice, from the nursery, while I was holding the baby downstairs.

## Run it

```sh
python3 main.py
```

The program writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network, no input files, no secrets.
